# NebulaTide 的 project 仓库 002

**本地语义化智能工作台**（暂定名）—— 面向 Windows 的桌面工作台：以「工作项目」为中心组织资源（网页 / 文件 / 文件夹 / 程序），并为受管文件夹赋予语义角色，实现结构化导入与可撤销整理。

**当前版本：v0.1 初版完成（2026-11-04）**

## v0.1 已实现

- 项目增删改查、搜索、重启持久化
- 数据与程序解耦：数据目录由用户指定，指针存在 `%APPDATA%\NebulaTide\Workbench\settings.json`
- 资源管理：网页 / 文件 / 文件夹 / 程序（`.exe` / `.com`），支持拖拽添加、查重、排序、启用/禁用
- 文件 / 文件夹 / 程序选择使用 Windows 原生对话框，初始位置为「此电脑」；文件选择保留 `.lnk` 快捷方式本身
- 从桌面导入：同时列出用户桌面和公共桌面（快捷方式 / 文件 / 文件夹 / 程序），选中后自动识别类型，`.lnk` 保留快捷方式本身
- 状态校验：失效路径标红并说明原因；启动后自动刷新
- 一键进入项目：后台线程逐个启动、进度显示、逐项结果汇总、事件记录
- 项目级「启动时尝试最大化（尽力）」
- 自动备份：数据目录 `backups/`，保留最近 5 份

## 已知边界

- 最大化是尽力而为：控制台程序有效；记事本、已运行的 VS Code 等常会忽略
- 不自动关闭任何资源
- 资源启动参数、AI 建议、待办事项留到后续版本
- 非空文件夹不允许作为数据目录

## 运行

双击 `启动工作台.bat`。

- **首次运行会自动创建 `.venv` 并安装依赖**（需要 Python 3.10+ 在 PATH 中，且联网）。
- 之后直接启动。
- 首次启动会让你选择数据目录。所有项目数据都保存在那里，程序目录不写数据。

也可以手动：

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m app.main
```

## 测试

```
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest
```
